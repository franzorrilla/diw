SISTEMAS / 06

Design Tokens: valores con significado.

Un token es un valor reutilizable y nombrado. Por ejemplo, type.body.size = 18px. El estilo Body puede utilizar ese valor; un cambio se propaga a las pantallas que lo comparten.

type.body.size 18 px
type.body.line 1,5
type.heading.font Schibsted Grotesk

Un estilo reúne valores; un token permite compartir cada valor.

VARIABLE / 13

Variable Fonts: muchas posibilidades, un archivo.

Una fuente variable puede interpolar estilos dentro de ejes definidos por su diseñador: peso (wght), anchura (wdth) o inclinación, entre otros.

VARIABLE / 14

Peso ≠ anchura.

Aumentar el peso engrosa los trazos; modificar la anchura cambia las proporciones. Estirar un texto artificialmente no equivale a utilizar un eje tipográfico auténtico.

VARIABLE / 15

Tamaño óptico: no es hacer zoom.

Algunas fuentes ofrecen el eje opsz: ajustan detalles del dibujo de los caracteres según el tamaño previsto de lectura. No todas las fuentes variables incluyen este eje.

ACCESIBILIDAD / 18

El zoom es una prueba de diseño.

Al ampliar al 200 %, el texto debe seguir siendo utilizable sin perder información ni controles. Revisa también el espaciado y la adaptación a pantallas pequeñas.

El contenido debe seguir siendo legible y accesible. Si amplías, observa los saltos de línea y evita recortar la información.

Simulación de crecimiento tipográfico, no sustituye la prueba real de zoom del navegador.
