¿QUIÉN MANDA EN ESTA PANTALLA?

Una web real. Una mirada de cinco segundos. Tres decisiones de diseño que tendrás que defender.

01 / OBSERVACIÓN

Tu primera mirada cuenta.

≈ 3 min

Abre la página real, mírala durante cinco segundos y vuelve aquí. Antes de analizar, registra qué te ha llamado la atención y qué esperabas encontrar.

Abrir la web ↗Se abrirá en otra pestaña. Si cambia, usa también la captura de referencia.

01. ¿Qué viste primero?

Señala lo que captó tu mirada sin analizar todavía si está bien o mal.

02. ¿Qué debería entender el visitante?

Imagina que llega por primera vez. Formula una pregunta concreta que la página debería responder pronto.

Regla del Lab

«No me gusta» no explica nada. Describe un elemento visible, el principio que interviene y el efecto que produce.

02 / ANÁLISIS

Señala tres puntos de fricción visual.

≈ 8 min

Pulsa tres lugares de la captura que quieras discutir. Después, explica cada uno usando un principio de composición. Al colocar un cuarto marcador, empezarás de nuevo. También puedes borrar los tres para recolocarlos.

CAPTURA DE REFERENCIA · ESCRITORIO

Con teclado: usa las flechas para mover el cursor y pulsa Intro o Espacio para colocar cada marcador. La captura fija la vista de escritorio; comprueba en la página real lo que observes. Los marcadores son anotaciones sobre esta imagen.

0 de 3 lugares señalados
Seis lentes para observar

Jerarquía · contraste · alineación · proximidad · repetición · equilibrio. Una decisión también puede funcionar: busca relaciones concretas y evita suponer que todo es un error.

Ejemplo ajeno a este caso: «El formulario separa la etiqueta del campo al que pertenece (proximidad). Esto obliga a buscar la relación entre ambos. Agruparía cada etiqueta justo encima de su campo». En tu análisis, sustituye el ejemplo por un elemento que hayas observado aquí.
03 / EXPERIMENTO

Cambia la relación de fuerzas.

≈ 5 min

Esta maqueta simplificada sirve para probar tres variables de composición. No reproduce la web real: úsala para predecir cómo cambiaría la lectura de la pantalla.

04 / CIERRE

Defiende una decisión, no un gusto.

≈ 4 min

Elige la mejora que aplicarías primero. Justifica su prioridad en una frase con esta estructura: decisión → efecto en la mirada → utilidad para la persona.

Antes de entregar, comprueba:

¿Has señalado elementos concretos de esta página? ¿Relacionaste cada observación con un principio? ¿Explicaste la consecuencia para quien la visita? ¿Reconociste una posible ventaja del diseño actual?

Puente a la sesión 2
